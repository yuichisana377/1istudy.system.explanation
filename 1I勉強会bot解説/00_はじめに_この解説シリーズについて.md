# `bot.py` 解説シリーズ — はじめに

対象ファイル：`python.bot.1istudy/bot.py`（約6900行）。Discord Bot本体と、Web側（`bot.1istudy.web`）が話しかけている裏側のFlask APIが、**1つのファイルに全部まとまっています**。

## このシリーズの位置づけ

これまでに以下の資料があります。

1. `1I勉強会webの裏側（設計の話）.md`（デスクトップ）… データの持ち方・セッションの仕組み・バックアップなど、**設計の考え方**をまとめた資料。
2. `1I勉強会web解説\`（フォルダ）… Web側（`bot.1istudy.web`）の各ページのHTML/CSS/JSを、**1行1行に近い粒度**でコードと対応させて説明した資料。
3. **このシリーズ（`1I勉強会bot解説\`）** … 1・2に対して「じゃあサーバー側の`bot.py`は実際どう書かれているのか」を、同じように**1行1行に近い粒度・関数ごと・プログラミング知識が無くても読める**形でカバーします。

1の資料が「なぜこう設計したか」という考え方の話だったのに対し、このシリーズは「実際のコードが具体的に何をしているか」という実装の話です。読み比べると理解が深まると思います。

## 用語について

プログラミング用語の説明は、Web解説シリーズの [../1I勉強会web解説/01_index_予定管理.md](../1I勉強会web解説/01_index_予定管理.md) にある「0. ミニ用語辞典」を再利用します。JSON・API・SHA・非同期処理など、共通する用語はそちらを参照してください。このシリーズだけに出てくる用語（Discord Bot特有の言葉など）は、初出の箇所でそのつど説明します。

## `bot.py`のとても大まかな地図

`bot.py`は上から下に、だいたいこの順番で並んでいます。

1. **設定・起動まわり**（1〜268行）… 環境変数の読み込み、Flaskアプリの初期化、リアルタイム通知（SSE）の仕組み、Discord Botの初期化。
2. **データ保存の共通部品**（269〜608行）… ファイルの読み書き・排他制御・運用ログ・設定ファイル・不正文字チェックなど、以降の全機能が使う土台。
3. **各機能のデータ層**（609〜1490行あたり）… 予定・学習ログ・勉強タイマー・ポイント・課題達成・ユーザー・セッション・Discord連携コードなど、機能ごとの「JSONファイルの読み書き」を行う関数群。
4. **Discordコマンド**（1490〜2024行）… `/add`や`/list`など、Discord上で使う`/`コマンドの実装（このBotの「Discord Bot」としての顔）。
5. **自動通知・監視ループ**（2025〜2203行）… 毎朝の予定通知や、勉強タイマーの自動休憩判定など、時間になったら自動的に動く処理。
6. **Flask API 群**（2204〜6778行）… Web側（`bot.1istudy.web`）の各ページが`fetch()`で呼んでいるHTTP APIの実装。**全体の半分以上を占める、このファイルの本体**です。予定管理・時間割・ユーザー認証・お知らせ・CardMaker（カード・フォルダ・並び順）・クイズ・学習ログの理解度データ、と機能ごとに並んでいます。
7. **バックアップとBotの起動処理**（6779〜末尾）… 毎晩のGitHubバックアップ、スケジューラーの登録、Discord接続が切れたときの再接続処理。

このシリーズでは、この順番に沿って複数のファイルに分けて解説していきます。Web解説シリーズと同じく「多く・重要な部分から優先」して作成し、同じ密度・同じ形式で最後まで続けます。
