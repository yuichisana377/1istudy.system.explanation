## CardMakerでできること（ざっくり）

- 科目ごとにデッキ（カードの束）を作り、フォルダで最大3階層に整理できる
- デッキは他の部員と共同編集でき、公開前は自分だけの下書きとして扱える
- カードは「問題・解答・解説」の暗記カード形式と、「問題・選択肢（2〜5個）・正解」の多肢選択形式の2種類
- 画像添付、理数記号（分数・ルートなど）の入力、CSVからの一括登録に対応
- フラッシュカード形式の学習（自動採点あり）、一人用の4択クイズ再生、問題と答えをまとめて見る一覧表示
- 「みんなでクイズ」（Quiz.htmlページ）用のデッキ選択にも使われる

## `Cardmaker.html` の画面構成（`<div class="screen">`による1ページSPA）

このページは別々のHTMLファイルに分かれておらず、1枚の`Cardmaker.html`の中に**複数の画面（`<div class="screen">`）を全部用意しておき、JSで`active`クラスを付け替えて見せる画面を切り替える**、という作りになっています（`showScreen(id)`という関数がこれを行います。8節で説明）。

| id | 画面 | 概要 |
|---|---|---|
| `screen-list` | デッキ一覧（ホーム） | フォルダ・デッキの一覧、右下の＋ボタン、クイズバナー、プレイ中/完了済みの一覧 |
| `screen-search` | 単語検索 | 全デッキ横断で問題文・解答を検索（`Cardmaker-search.js`が担当） |
| `screen-new` | 新しいデッキ作成 | 科目選択・公開予定トグル・多肢選択デッキトグル・セット名入力 |
| `screen-edit` | カード編集 | CSV読み込み・問題文/解答/解説（または選択肢）の入力・作成済みカード一覧 |
| `screen-study` | 学習（フラッシュカード） | 問題→解答を1枚ずつめくって学習、自動採点、わからないマーク |
| `screen-quiz-play` | 一人用4択クイズ | 「クイズ過去問」フォルダ専用の4択クイズ再生（`Cardmaker-quizplay.js`が担当） |
| `screen-list-view` | 一覧表示 | 問題と答えをまとめて見る一覧、わからないだけ絞り込み（`Cardmaker-listview.js`が担当） |

これに加えて、下から出てくる小さいポップアップ（`.modal-overlay` / `.modal-sheet`、他ページの「モーダル」と同じ役割）が多数あります：追加の選択（デッキ/フォルダ）・フォルダ名入力・フォルダメニュー・移動先選択・再生モード選択・デッキ名変更・デッキメニュー・削除依頼理由入力・カード編集。

## KaTeX（数式表示ライブラリ）の読み込みとセキュリティ対応（11〜18行）

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/katex@0.16.21/dist/katex.min.css">
<script defer src="https://cdn.jsdelivr.net/npm/katex@0.16.21/dist/katex.min.js"></script>
<script defer src="https://cdn.jsdelivr.net/npm/katex@0.16.21/dist/contrib/auto-render.min.js"></script>
```
- **KaTeX**は、分数やルートのような数式を教科書のようにきれいに表示するための外部ライブラリです（このサイトが唯一使っている外部CDN読み込みのJS/CSSで、Cloudflareの`_headers`のCSP設定で許可されているのもこのためです）。
- コメントにある通り、以前使っていたバージョン（0.16.11）に「出力のエスケープが不十分」という既知のセキュリティ上の弱点があったため、0.16.21以降へ更新した経緯が記録されています。他の部員が作ったデッキの問題文・解答（＝自分では信用できない入力）がここで表示される経路なので、単なるバージョンアップ作業ではなく、セキュリティ対応として扱われています。
