# 時間割ページ — 全体像と `Timetable.html` の構造

対象：`bot.1istudy.web/Timetable.html`（687行）、`bot.1istudy.web/Timetable.js`（1871行）。

このページでできることは大きく2つあります：
1. **曜日ごとの時間割の表示・変更**（今週の時間割、休講・時限変更・曜日入れ替え・休校設定、月間カレンダー、前期/後期など学期ごとの基本時間割）
2. **予定管理（[../01_index_予定管理.md](../01_index_予定管理.md)と同じ機能）を、時間割の画面からも直接使えるようにしたもの**（追加・編集・削除のFAB、モーダル、自作カレンダーなど）

2番目は`index.html`の`Plan.js`とほぼ同じコードがこのファイルの中にもう一度書かれています（コピーに近い）。そのため、このドキュメントでは重複する部分は簡潔にまとめ、**時間割そのものに関する部分（このページ独自の内容）を中心に**解説します。
